# WIT Language Server v0.1.1

## Distribution recovery

- Restore GitHub Release distribution after the previously published immutable
  `v0.1.0` release was deleted. GitHub permanently reserves tag names that
  were used by immutable releases, so `v0.1.0` cannot be recreated.
- No intended language-server behavior changes from `v0.1.0`; the native LSP
  source is unchanged apart from the package version.
- Publish fresh native binaries for macOS ARM64/x86_64, Linux GNU ARM64/x86_64,
  and Windows x86_64 MSVC with checksums, provenance, redistribution notices,
  project licenses, and GitHub attestations.

## Compatibility

The Zed adapter remains pinned to LSP `0.1.0` until `v0.1.1` is published and
qualified. A follow-up change will advance
`package.metadata.zed-wit.runtime-lsp-version` to `0.1.1`.
