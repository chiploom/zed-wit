# WIT Language Server v0.1.2

## Grammar alignment

- Rebuild the native language server against the requalified Bytecode Alliance
  `tree-sitter-wit` revision
  `f777cdbe11281ccc68ffa30bd7ea34cdf4ddbec6`.
- The upstream grammar change exposes public supertypes while preserving the
  concrete syntax nodes and fields used by the language server's analysis and
  formatting paths. No concrete language-server behavior change is intended.
- Publish fresh native binaries for macOS ARM64/x86_64, Linux GNU ARM64/x86_64,
  and Windows x86_64 MSVC with checksums, provenance, redistribution notices,
  project licenses, and GitHub attestations.

## Compatibility

The Zed adapter remains pinned to LSP `0.1.1` until `v0.1.2` is published and
qualified. A follow-up change will advance
`package.metadata.zed-wit.runtime-lsp-version` to `0.1.2`.
