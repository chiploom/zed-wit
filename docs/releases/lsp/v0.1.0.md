# WIT Language Server v0.1.0

## Highlights

- Native WIT language server with parser-backed diagnostics, formatting,
  completion, hover, definition, references, and safe unresolved-type typo fixes.
- Multi-file package analysis with direct `deps/` files and one-level dependency
  package directories.
- Native binaries for macOS ARM64/x86_64, Linux GNU ARM64/x86_64, and Windows
  x86_64 MSVC.
- SHA-256 sidecars, target-specific redistribution notices, build provenance, and
  GitHub artifact attestations for every native release artifact.

## Distribution

The GitHub release is immutable. Each native binary is published with its
matching `.sha256`, `.provenance.json`, and `.licenses.txt` files.

The repository also contains the Zed extension source used to integrate this
server, but `v0.1.0` is not a Zed-extension publication. The extension remains
separate from this LSP release and is not yet published through the Zed extension
registry.
