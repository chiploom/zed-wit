# Zed WIT extension 0.5.0

This release introduces Chiploom's implementation of the WIT extension for Zed, succeeding the original extension by Valentine with their permission.

The extension provides modern WebAssembly Interface Types (WIT) support, combining syntax-aware editing with a native language server for diagnostics, formatting, completion, navigation, and more.

## Highlights

### Language support

- Updated Tree-sitter grammar from the Bytecode Alliance, supporting modern WIT syntax.
- Syntax highlighting for packages, interfaces, worlds, resources, types, functions, and annotations.
- Automatic `.wit` file recognition, indentation, bracket matching, code outlines, and Vim text objects.
- Snippets for common WIT declarations, including packages, interfaces, worlds, functions, imports, exports, and types.

### Language server

- Native WIT language server built on upstream `wit-parser` semantics.
- Syntax, name-resolution, and type diagnostics with support for unsaved changes.
- Scope-aware completion for WIT types and declarations.
- Hover information, go to definition, and find references.
- Quick fixes for unresolved types with matching names in scope.
- Multi-file package analysis, including sibling files and local `deps/` dependencies.

### Formatting

- Topiary-based document formatting.
- Preserves comments and supports consistent, repeatable formatting.
- Rejects formatting requests for syntax-invalid documents rather than producing potentially incorrect output.

### Installation and compatibility

- Automatically downloads the native WIT language server when needed, without requiring a separate manual installation.
- Uses the published WIT Language Server `v0.1.2` release.
- Verifies downloaded binaries against their SHA-256 checksums and caches verified executables.
- Detects corrupted or incomplete cached downloads and recovers automatically.
- Provides native binaries for macOS (ARM64 and x86_64), Linux GNU (ARM64 and x86_64), and Windows (x86_64).

## Validation

- 174 automated workspace tests passed.
- Formatting, Clippy, dependency checks, and WebAssembly adapter build passed.
- Real-Zed hosted integration testing passed on macOS ARM64, covering initial installation, cache reuse, corrupted binary recovery, and missing checksum recovery.
- Real-Zed GUI qualification has been recorded for macOS ARM64. Hosted runtime qualification on the other supported platforms remains pending.

## Known limitations

- Package dependency discovery is limited to supported local file and directory layouts.
- Remote dependency fetching and encoded binary component dependencies are not supported.
- Some newer WIT grammar constructs may be recognized syntactically but remain restricted by upstream semantic feature gates.

## Maintenance

Chiploom is taking over maintenance of the existing `wit` extension registry entry with permission from Valentine, the original author.

Thanks to [Valentine](https://github.com/valentinegb) for creating the original [Zed WIT extension](https://github.com/valentinegb/zed-wit) and approving the transition.

The Zed registry update is a separate step from this GitHub extension release.
