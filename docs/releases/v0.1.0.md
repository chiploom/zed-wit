WIT for Zed v0.1.0 is the first public release of the rebuilt extension.

## Highlights

- First-class `.wit` file support in Zed with the canonical Bytecode Alliance
  Tree-sitter grammar.
- Native WIT language server with parser-backed diagnostics, formatting,
  completion, hover, definition, references, and safe unresolved-type typo fixes.
- Multi-file package analysis with direct `deps/` files and one-level dependency
  package directories.
- WIT-aware snippets, outline support, brackets, indentation, comments, and Vim
  text objects.
- Native language-server downloads for macOS ARM64/x86_64, Linux GNU ARM64/x86_64,
  and Windows x86_64 MSVC.
- SHA-256 sidecars, target-specific redistribution notices, build provenance, and
  GitHub artifact attestations for every native release artifact.

## Distribution

The GitHub release is immutable. Each native binary is published with its
matching `.sha256`, `.provenance.json`, and `.licenses.txt` files.

The extension is not yet published in the Zed extension registry. Until registry
succession is complete, install this repository as a development extension in
Zed.
